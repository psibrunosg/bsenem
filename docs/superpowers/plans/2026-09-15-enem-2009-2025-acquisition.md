# ENEM 2009-2025 Official Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Download, validate, and catalogue at most 34 canonical official Inep ENEM booklets and matching answer keys: one regular-application booklet for each day of every edition from 2009 through 2025.

**Architecture:** Discover all sources only from Inep's official “Provas e Gabaritos” index, then select two canonical regular-application cadernos per year before downloading. Color/order variants, PPL, reaplicação, digital and accessibility-only documents remain inventory evidence, not download targets. Each retained source gets a manifest record with URL, hash, byte size, page count and failure state. No question transcription, SQL import, OCR or player publication belongs to this work.

**Tech Stack:** Node.js built-in `fetch`, `crypto` and `fs`; Poppler `pdfinfo` and `pdftoppm`; JSON manifests.

**Spec:** User request, 2026-09-15. Official index: https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enem/provas-e-gabaritos

**Execution status (2026-09-15):** Official discovery produced 791 source records and canonical selection produced 34 cadernos plus 34 matching gabaritos. The official host was unavailable, so the user authorized the Projeto Medicina mirror. All 68 PDFs were downloaded into `content/enem/official-pdfs/`, preserving each original Inep URL and the mirror URL in the manifest. SHA-256, PDF signature and Poppler page-count validation passed for all files (1,186 pages); representative visual renders were legible.

## Global Constraints

- Scope: two regular-application `prova` PDFs per year, 2009-2025, plus matching `gabarito` PDFs: maximum 34 cadernos and 34 matching gabaritos. Never download all color/order variants.
- Select from official visible labels: Day 1 prefers `Caderno 1 - Azul`; Day 2 prefers `Caderno 5 - Amarelo`; where unavailable, select first regular printed caderno explicitly labelled for that day and record fallback reason. Do not guess a missing day.
- PPL, reaplicação, digital, accessibility-only and `Tema da Redação` material remains raw-inventory evidence with exact reason. It is not part of 34-caderno archive.
- Preserve original PDF bytes. Do not OCR, merge, crop, rename semantically or replace a source file.
- Download only HTTPS URLs on an `inep.gov.br` host. Reject unsafe redirect, non-200 response, non-PDF content type or missing `%PDF-` signature.
- Store assets locally under `docs/sources/enem/`; record every success and failure. Never silently skip a year, application or document.
- Existing 2025 files remain intact. A changed hash is a `hash-conflict`, not an overwrite.
- PDFs and rendered samples stay ignored by Git unless user later authorizes large binary commits; scripts, tests and JSON ledgers are commit candidates.
- Source preservation is not editorial approval. Question/player integration remains blocked until separate image and fidelity work passes.

## Acceptance Criteria

- Raw inventory preserves all discovered official sources, but download ledger contains no more than 34 selected cadernos and 34 matching gabaritos.
- Every retained PDF has URL, SHA-256, size, page count, timestamp and valid signature.
- Unsafe or corrupt downloads fail closed and remain visible in manifest.
- Reruns never overwrite a verified differing file or select duplicate material for a year/day.
- Visual samples render for every retained document.
- No exam content enters SQL/player and no PDF is committed without explicit binary-storage approval.
